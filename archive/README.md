# Archived images

Photos that are no longer used on the website. They are kept here, outside
`public/`, so they are **not** published on pupacenter.org, but are retained
in the repository (PUPA keeps photo files even when a person or photo is
removed from the site).

To use one again, move it back into `public/images/` (same sub-folder) and
reference it from the page or article.

Note: if this repository is public on GitHub, these files can still be
downloaded from GitHub itself.
