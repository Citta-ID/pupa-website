# PUPA Center website

The new website for PUPA Center (pupacenter.org), replacing the Squarespace site.

- Built with [Astro](https://astro.build) — a fast static site generator
- Bilingual: English at `/`, Indonesian at `/id/`
- Hosted for free on Cloudflare Pages

## Editing content

- Homepage text (both languages): `src/i18n/home.ts`
- Menu and footer text (both languages): `src/i18n/ui.ts`
- Pages live in `src/pages/` (English) and `src/pages/id/` (Indonesian)

## Running locally (optional, for developers)

```
npm install
npm run dev
```

## Deployment

Cloudflare Pages builds automatically on every push to `main`.
Build command: `npm run build` · Output directory: `dist`

## Images

All images are self-hosted in `public/images/` — the site has ZERO dependency on
Squarespace. To add a new photo: optimize it to max 1600px, place it in
`public/images/`, and reference it as `/images/filename.jpg`.

## How the build works (added November 2026)

`npm run build` runs Astro and then a small PUPA step (`integrations/pupa-post-build.mjs`) that:

- makes smaller WebP copies of every JPEG photo used on a page (in `dist/_img/`) and adds
  `srcset`/`sizes`, so phones download small files. Keep adding photos as JPEGs in
  `public/images/` as before — the copies are made automatically. If a photo shows at an
  unusual size, give its `<img>` its own `sizes` attribute.
- writes a fingerprint of every inline script into the security policy in `dist/_headers`,
  so only the site's own scripts can run. Don't use inline event handlers such as
  `onclick="…"` — they are blocked. Put the code in a `<script>` instead.

`npm run check` checks the built site (missing files, headings, descriptions, scripts).
GitHub runs build + check on every push ("Build check" in the Actions tab).

Fonts are self-hosted from the `@fontsource` packages via `src/styles/fonts.css`, which is
generated by `node scripts/build-fonts-css.mjs` (re-run it after updating a font package).
